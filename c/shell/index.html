Shell Yeah

The server has a handy ping tool. It runs ping -c 1 <your input> in a Linux shell. In a shell, a semicolon ; means “and then run this next command.”

$ ping tool v1.0. try: 8.8.8.8
ping -c 1

The server has no internet, so pings fail. That's fine. The ping isn't the interesting part.
