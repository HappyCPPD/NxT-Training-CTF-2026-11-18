Gauntlet Launch Console

stage 4/6 · pwn

The gauntlet's launch console. It wants the launch code, then your callsign. The firmware stores your callsign in an 8-byte box, and the very next byte is your clearance level. Only clearance 90 may launch.

struct console {
  char callsign[8];   // 8 bytes
  char clearance;     // must be exactly 90
};
gets(c.callsign);     // no length check
