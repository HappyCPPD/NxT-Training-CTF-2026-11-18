Too Many Bytes, Bestie

This login program stores your name in a 16-byte box. Right after it in memory sits one byte called is_admin. The dev used gets(), which copies everything you type.

struct user {
  char name[16];   // 16 bytes
  char is_admin;   // 0 = nope, anything else = admin
};
gets(u.name);      // reads as much as you type. what could go wrong
