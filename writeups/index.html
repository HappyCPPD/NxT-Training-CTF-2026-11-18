NxT CTF: Writeups

How every challenge works, how to solve it, and the real-world lesson behind it. 31 challenges, 2750 points.

Quick tools: CyberChef for decoding, dCode for ciphers, CrackStation for hashes, your browser's DevTools (F12), and on Linux/WSL: strings, file, exiftool, git.

About this replay. Everything runs in your browser. The challenges that needed a server on the night are rebuilt to work the same way: the SQL injection runs on a real SQLite engine (WebAssembly), the XSS admin bot is a hidden browser frame on the page, and the command injection runs on a small simulated shell.

The flag is printed in the challenge. Copy it, braces included.

crypto

Group Chat Leak (50)

Theo sent Jules TnhUe25vX2NhcF90aGlzX2lzX2Jhc2U2NH0=. It's not a password, it's Base64: only letters, digits, + and /, often ending in =. Put it through CyberChef From Base64.

Flag: NxT{no_cap_this_is_base64}

Lesson: encoding is not encryption. Anyone can decode Base64, with no key needed. Pro tip: Base64 that starts with TnhUe decodes to NxT{, so learn to spot it.

Caesar Salad (50)

AkG{irav_ivqv_ebg13}. Every letter is shifted by the same amount. A → N is a shift of 13, so this is ROT13. Drag the decoder ring to 13, or use CyberChef ROT13.

Flag: NxT{veni_vidi_rot13}

Lesson: a Caesar cipher has only 26 possible keys, so you can just try them all (brute force).

Uno Reverse Card (50)

}drac_esrever_onu{TxN is just the flag written backwards. Read it right to left, or CyberChef Reverse.

Flag: NxT{uno_reverse_card}

Lesson: obfuscation isn't security.

Emoji Movie (75)

Each emoji is one letter (a substitution cipher), and the cheat sheet is the key. Swap each emoji for its letter. Underscores stay underscores.

Flag: NxT{no_thoughts_just_vibes}

Lesson: with the key, any substitution cipher is readable. Without it, you'd use letter frequency (E, T, A are most common in English).

Beep Boop (75)

transmission.wav is Morse code: short beep = dot, long beep = dash. Upload it to an online Morse audio decoder, or decode the blinking lamp by hand:

... . -. -.. / -- --- .-. . / -- . -- . ... = send more memes

Flag: NxT{send_more_memes}

Lesson: Morse is just another alphabet, and decoding audio is a real forensics skill.

All I See Is ******* (100)

2ab96390c7dbe3439de74d0c9b0b1767 is an MD5 hash. Hashes can't be reversed, but common passwords have already been hashed and stored in huge lookup tables. Paste it into CrackStation: hunter2. (Yes, it's the classic old chat-room joke where someone's password "shows up as stars".)

Flag: NxT{hunter2}

Lesson: unsalted MD5 is broken for passwords. Real sites use slow, salted hashes like bcrypt or argon2.

It's Over 9000 (100)

The page saves your "game" in the browser. DevTools, then Application (Storage in Firefox), then Local Storage, then the key nxt_save. The flag is in the JSON.

Flag: NxT{its_over_9000}

Lesson: browser storage is fully readable and editable by the user. Never keep secrets or trusted data there.

Bobby Tables' Revenge (100)

The login builds SQL by gluing your input into the query:

SELECT username, role FROM users WHERE username = '<you>' AND password = '<you>'

Username admin' -- turns it into:

... WHERE username = 'admin' --' AND password = '...'

The ' closes the string early and -- comments out the password check. ' OR 1=1 -- also works (it logs you in as the first user, who is admin). Typing just ' gives an SQL error, which is the clue that your input reaches the query.

Flag: NxT{or_1_equals_1_lol}

Lesson: SQL injection. The fix is parameterized queries, where input is never glued into SQL text.

XSS Marks the Spot (150)

Your guestbook renders messages as raw HTML, so any <script> you post runs in the browser of whoever views it. The admin bot holds the flag in a cookie and opens your guestbook when you report it.

Reading document.cookie isn't enough: your script must send it back. Use the hidden helper:

<script>reply(document.cookie)</script>

or the manual version:

<script>fetch('post',{method:'POST',body:new URLSearchParams({m:document.cookie})})</script>

Report to admin, wait for the refresh, and the admin's message admin=NxT{...} appears.

Flag: NxT{xss_marks_the_spot}

Lesson: cross-site scripting. User input rendered as HTML lets attackers run code in other people's browsers and steal their sessions. The fix is to escape output (and use HttpOnly cookies).

pwn

Too Many Bytes, Bestie (100)

name is 16 bytes and is_admin is the very next byte. gets() copies everything you type. A 17-character name like AAAAAAAAAAAAAAAAB spills its 17th byte into is_admin (B = 66, which isn't 0), so you're admin.

Flag: NxT{too_many_bytes_bestie}

Lesson: buffer overflow. Writing past a buffer overwrites what's next to it. That's why gets() is banned in modern C.

Infinite Money Glitch (75)

The shop only checks cost > coins. Buy -100000 stickers: cost = -100000 × 10 = -1,000,000, so the shop adds a million coins. Then buy the flag.

Flag: NxT{infinite_money_glitch}

Lesson: validate every input on the server, including "impossible" values like negatives.

Shell Yeah (100)

The server runs ping -c 1 <your input> in a real shell. ; ends one command and starts the next:

8.8.8.8; ls
8.8.8.8; cat flag.txt

Flag: NxT{shell_yeah}

Lesson: command injection. Never pass user input to a shell. (Tonight's container was read-only with no network, so nobody could break anything.)

rev

Read the Code, Luke (75)

The checker compares your input to a list of numbers. Those are ASCII codes: 78 = N, 120 = x, 84 = T, 123 = {... CyberChef From Decimal (comma delimiter) turns the whole list back into text.

Flag: NxT{read_the_code_luke}

Lesson: reverse engineering is reading what the code does and working backwards.

No Strings Attached (75)

vault is a compiled Linux program, but programs keep their text readable inside the binary:

strings vault | grep NxT

(You'd also spot the password, correct horse, the same way.)

Flag: NxT{strings_attached}

Lesson: strings is usually the very first move on an unknown binary.

Math Is Mathing (75)

pin * 3 + 7 == 2026. Undo each step in reverse order: 2026 - 7 = 2019, then 2019 ÷ 3 = 673.

Flag: NxT{math_is_mathing}

Lesson: to find the input a program wants, invert its logic.

forensics

Kinda Sus (50)

The "empty" space has text the same color as the background. Highlight it with your mouse (or Ctrl+A).

Flag: NxT{that_text_is_kinda_sus}

Lesson: what's on screen isn't everything that's on the page.

Is This a PNG? (75)

Three files called .docx, but extensions lie. The first bytes (magic bytes) tell the truth:

File First bytes Really
homework_1 89 50 4E 47 (.PNG) PNG
homework_2 25 50 44 46 (%PDF) PDF
homework_3 50 4B 03 04 (PK) ZIP

On Linux, file homework_* tells you instantly. The ZIP's README explains the format.

Flag: NxT{png_pdf_zip}

Lesson: never trust file extensions.

Zoom and Enhance (125)

The flag is written just 2 shades brighter than the darkest part of the photo, invisible to the eye. Stretch the dark tones: shadows ~6, highlights ~14, then zoom into the lower right. (GIMP Levels or StegSolve work too.)

Flag: NxT{nicholaus_chicken_feet}

Lesson: images can hide data in tiny differences your eye can't see.

Mirror Mirror (100)

The webcam's mirror filter makes the right half an exact reflection of the left, except where the flag was added at +/-3 brightness on the right half. Subtract the photo from its own horizontal flip: everything cancels to black except the flag (it shows up twice, once mirrored). GIMP: duplicate layer, Flip Horizontally, layer mode Difference, then Levels with the white point at 3. Python: ImageChops.difference(img, img.transpose(Image.FLIP_LEFT_RIGHT)).

Flag: NxT{mirror_mirror_on_the_wall}

Lesson: "almost identical" is a signal. Diffing against what something should be (a reflection, a previous version, a known-good file) finds tampering.

Two-Faced (125)

Visual cryptography. The left half's bit plane 0 is a random key; the right half's bit plane 0 is key XOR flag. Each one alone is perfect static (a one-time pad). Crop the halves (x 0-399 and 400-799), XOR them (StegSolve Image Combiner, or Python), and the flag appears in plane 0.

Flag: NxT{two_halves_one_secret}

Lesson: a one-time pad is unbreakable alone, but the key and ciphertext together give everything away. Secret sharing splits a secret so no single piece leaks anything.

Going in Circles (150)

StegSolve Blue plane 0 shows a ring around the centre star with two tracks. The outer track ticks on/off to mark 208 slots; the inner track is the data, one bit per slot. Read clockwise from 12 o'clock, white = 1, black = 0, group into bytes (CyberChef From Binary).

Flag: NxT{round_and_round_we_go}

Lesson: LSB stego doesn't have to be row-by-row. Tools like zsteg only scan in raster order, so a circular layout slips past them; sometimes you have to look at the plane and work out the layout yourself. The timing track is the same idea as clock lines in QR codes and barcodes.

Overshare (125)

Omar posts everything. Put the pieces together:

  1. The terminal screenshot (open it full size): PASSWORD IS MOCHI + MOCHI BIRTHDAY + MY BIRTHDAY
  2. Which cat is Mochi? The grey fluffy one. Mia's comment names him on his "2nd birthday" post, dated June 3, 2025, so he was born 03/06/2023. (Hoshi's birthday and Maro vs Taro are decoys.)
  3. Omar's birthday: the "28 today!!" cake post is dated March 14, 2026, so he was born 14/03/1998. (Mom's birthday is a decoy.)
  4. The portal says dates are DDMMYYYY. Log in as omar / mochi0306202314031998.

Flag: NxT{dont_overshare_online}

Lesson: people leak their passwords through posts, photos and comments. Don't build passwords from personal facts, and check your screenshots before posting.

boss

I Am Inevitable (250)

One challenge, six stages, one per category. Each stage gives you the address of the next.

  1. crypto: the intercepted message is Base64. From Base64 gives scrambled text, and ROT13 on that reveals: "thanos here. the vault is at https://happycppd.github.io/NxT-Training-CTF-2026-11-18/c/web/boss/vault-2972f5 - guests only, unless you know the trick."
  2. web: the vault sets a cookie vault_role=guest. In DevTools, go to Application > Cookies, change it to admin and reload. The admin view links gauntlet_check.py and names the launch console.
  3. rev: the script accepts a code when (code ^ 1337) == 2021. XOR undoes itself, so code = 2021 ^ 1337 = 732.
  4. pwn: the console stores your callsign in 8 bytes and the next byte is clearance, which must be exactly 90. 90 is ASCII Z, so the callsign is 8 characters then a Z, like AAAAAAAAZ. With code 732, it launches and links the gauntlet photo.
  5. forensics: exiftool gauntlet-9d41a0.png (or strings) shows the PNG comment: last seen at 40.6892, -74.0445 | final gate: https://happycppd.github.io/NxT-Training-CTF-2026-11-18/c/web/boss/gate-7f4fef.
  6. osint: 40.6892, -74.0445 in Google Maps is the Statue of Liberty. Enter it at the final gate.

Flag: NxT{six_categories_one_snap}

Lesson: real attacks chain skills from different areas. One weak link in each layer is all it takes.

The one rule from tonight

Never trust the client. HTML, JavaScript, browser storage, form values and "impossible" numbers are all in the user's hands. The server has to check everything.
